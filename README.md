# CPRG 303 React Native Router Practice

## Introduction

This activity focuses on practicing routing in React Native applications using Expo Router. Students will work through a series of challenges that build on each other, starting with basic routing implementation and progressing to more advanced navigation UI refactoring.

The activity is divided into three main parts:

1. **Routing Implementation**: Basic dynamic routing and screen configuration
2. **Navigation UI Refactor**: Improving the navigation experience through consistency and reusable components
3. **Root Stack Navigation**: Advanced stack navigation configuration

## Branch Structure

The activity is organized into separate branches for each challenge set:

1. **main branch**: Contains the base project structure and initial setup
2. **routing-challenges**: Contains the first set of routing implementation challenges
3. **navigation-refactor**: Contains the navigation UI refactoring challenges
4. **root-stack-challenges**: Contains the advanced root stack navigation challenges

## Getting Started

1. Start with the **main branch** to understand the base project structure
2. Move to the **routing-challenges** branch to work on the initial routing implementation
3. After completing the routing challenges, switch to the **navigation-refactor** branch for the UI refactoring tasks
4. Finally, work on the **root-stack-challenges** branch for the advanced stack navigation tasks

Each branch contains specific challenges marked with comments that guide students through completing the implementation. The branches build on each other, so it's recommended to complete them in order.
